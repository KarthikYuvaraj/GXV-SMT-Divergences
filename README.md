✦ GXV SMT Divergences-Lite

Core idea

SMT divergence is the structural disagreement between correlated assets.
For example:

One index makes a new high while another correlated index fails to confirm.*
*
One forex pair sweeps a low while the related pair holds above its low.
One market shows relative strength while another shows weakness around a liquidity zone.

These moments can become powerful confluence when combined with market structure, liquidity, time of day, session context, and a complete trading model.

GXV SMT Divergences-Lite was built to make those moments easier to see without turning the chart into a mess.

How to use it

1. Add the indicator to a clean chart.
2. Use Auto correlation mode for fast setup, or switch to Manual mode if you want to choose your own comparison assets.
3. Enable only the SMT ranges that match your trading model.
4. Use the session filter if your SMT approach is built around Asia, London, NY-AM, or NY-PM.
5. Treat SMT as confluence, not as a standalone entry trigger.
